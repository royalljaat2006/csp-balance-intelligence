How the figures fit together

Per-account averages are rupees per account; combined balances are the whole CSP.

  1. 1. Starting point: the SBI-reported average

    {{ x.baseline.per_account_average|inr }}

    Per account. Received {{ x.baseline.received_on|date:"j M Y" }} ({{ x.baseline.days_since_received|ago_days }}). It starts a new cycle on that day; bank movement counts from the next day. Source: {{ x.baseline.source }}.

    {{ x.account_count.effect }} Last read {% if x.account_count.last_reading %}{{ x.account_count.last_reading|date:"j M" }} ({{ x.account_count.reading_age_days|ago_days }}){% else %}never{% endif %}{% if x.account_count.stale %}. Stale or invalid latest reading: the last valid count is being used.{% endif %}

  3. 3. Combined balance at the baseline

    {{ x.combined_baseline|inr }}

    Average × account count = {{ x.baseline.per_account_average|inr }} × {{ x.account_count.at_baseline|intc }}. This is the whole CSP, not one account.

  4. 4. Eligible deposits since then

    {{ x.movement.deposits|inr }}

    Pool-account debits of the approved deposit types, matched exactly to this CSP, after {{ x.movement.from_exclusive|date:"j M" }}. They raise the balance.

  5. 5. Eligible withdrawals since then

    {{ x.movement.withdrawals|inr }}

    Pool-account credits of the approved withdrawal types, same rules. They lower the balance.

  6. 6. Net eligible movement

    {{ x.movement.net|signed_inr }}

    Deposits minus withdrawals over {{ x.movement.window_days }} day{{ x.movement.window_days|pluralize }}: {{ x.movement.complete_days }} final, the rest provisional{% if x.movement.coverage is not None %} ({{ x.movement.coverage|pct0 }} of days proven complete){% endif %}. A day with no statement is carried forward, never counted as zero activity.

  7. 7. Estimated combined balance

    {{ x.combined_now|inr }}

    Step 3 + step 6.{% if x.movement.reconciles is True %} The stored daily rows add up to this figure.{% elif x.movement.reconciles is False %} The stored daily rows do not add up to this figure. Do not rely on it until checked.{% endif %}

  8. 8. Estimated average per account

    {{ x.estimate.per_account_average|inr }}

    Step 7 ÷ {{ x.account_count.current|intc }} accounts. {{ x.estimate.status|est_label }}. {{ x.estimate.reason_words }}{% if x.estimate.expected_error_pct is not None %} Measured typical error: {{ x.estimate.expected_error_pct|floatformat:1 }}%.{% endif %}
