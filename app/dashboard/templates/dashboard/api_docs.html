Calling an endpoint from here still needs a real X-API-Key — your dashboard login doesn't grant that; the two are deliberately separate credential boundaries.

Authentication

v1.0.0

Every business endpoint requires an X-API-Key header, scoped per consumer (never a flat shared key). Issue one:

docker compose exec web python manage.py create_api_key <consumer-name> --scopes csp:read,balance:read

The raw key prints once — copy it immediately. See docs/API-CONSUMERS.md for the registry of who holds which key.
