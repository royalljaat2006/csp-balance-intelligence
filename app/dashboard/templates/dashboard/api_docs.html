Keys and scopes

Every endpoint except health needs a key, issued per consumer with only the scopes it needs.

ScopeCovers
csp:readCSP identity and monthly summary
balance:readBalances and history
incentive:readRule #19 position
projection:readMonth-end projection (production)
transaction:readWorkbook transactions
comparison:readDay-by-day comparisons
report:readOverview, data readiness, review, SBI comparison, estimates and month-end outlook

To issue a key, run python manage.py create_api_key <name> --scopes csp:read,balance:read on the server. The key prints once. Never paste a key into a chat or ticket.
