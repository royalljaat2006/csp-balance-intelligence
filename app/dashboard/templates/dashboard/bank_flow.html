Bank-Flow Validation

Does CSP-wise transaction flow from the SBI pool-account statement predict the Calling Sheet Avg Balance? This page ingests and audits the statements and reports a held-out evaluation. It is analysis only: nothing here is an actual balance, the Calling Sheet remains the balance source, and a prediction is shown only as a labelled prediction.

Reading this page honestly. Pool-account credits/debits are pool accounting direction, not the effect on a CSP's own customer balances. The signed customer-flow definition is a hypothesis. A model is trusted only if its status below says VALIDATION PASSED.
